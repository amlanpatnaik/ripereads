# Ripe Reads — PRD

## Problem statement (original, abridged)
Static-first content/reference site: first-person age-readiness ("ripeness") ratings for romantasy/crossover fantasy. Citation-first SEO: pre-rendered HTML with correct metadata on every page. Validator-enforced non-negotiables (unmarked books carry no first-person experience, null beats fabrication, no "inappropriate", --stamp only on the stamp, --green renders wine, rel=sponsored on affiliate links, zero commercial links under /challenged/, 700–1800 words per book page, no orphans, /about/ SLOTs keep build red until filled). Seed: 15 B1 titles + 6 vibes lists, all `unmarked`.

## User decisions
- Spec docs (BUILD/DESIGN/CONTENT/STRATEGY/PUBLISHED.md) were not available; built from the plan alone, owner to reconcile.
- Stack: keep CRA (preview works) + build-time pre-render step (option 2b). No backend in critical path.
- Seed titles: agent-picked 15; cover chain Open Library → Google Books → FallbackCover; forms are UI stubs.
- Credit-conscious build: design_agent skipped, plan's "circulation desk × orchard" direction used directly.

## Architecture
- `frontend/src/data/*.mjs` — books (3 files), vibes, rubric; `covers.json` generated by `scripts/resolve.mjs`.
- `frontend/src/lib/links.mjs` — generated internal linking (hubs, 3 step-down/3 step-up, vibes backlinks, orphan graph, `bookPageText`).
- `frontend/src/lib/seo.mjs` — 4 JSON-LD blocks (Book, Review, FAQPage, BreadcrumbList), meta.
- `frontend/scripts/validate.mjs` (prebuild), `seo.mjs` (sitemaps split, robots.txt w/ AI crawlers, llms.txt), `prerender.mjs` (postbuild: per-route index.html with meta + JSON-LD + static text).
- Pages: Home, /books/:slug (10 verbatim H2s), ages/grades/series hubs (+ maturity-drift SVG), read-next, lists, vibes (inline band+signal, pin), challenged, about/method/shelf/corrections/editorial-policy, find (Fuse.js), quiz, disagree, /og/:slug, /pin/:slug.
- Fonts self-hosted via @fontsource (Fraunces, Literata, Space Mono).
- `site.config.mjs` (not .json — Node ESM/JSON import attribute incompatibility with CRA babel).
